# Журнал изменений (Changelog)

Все заметные изменения в проекте «Лаборатории» будут фиксироваться в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com).

---

## [v1.0.0-ja] — 2026-10-21
### Добавлено
* **Система Журнала посещений:** Запущена первая стабильная архитектура системы автоматизации Журнала.
* **Фронтенд сайта:** Интегрирован Jekyll-модуль страницы `_pages/journal-attendance.md` с инструкцией для учителей и Liquid-разметка интерфейса.
* **Логика и бэкенд:** Подключена сквозная цепочка из 7 JavaScript-модулей управления формой и Python-скрипты сборки отчетов с Телеграм-ботами.

*Примечание: Исходный код автоматизации, базы данных расписания и скомпилированный ZIP-архив фронтенда этой версии официально перенесены и версионируются в изолированном репозитории. Раздел релизов сайта не затрагивается.*

👉 [Изучить официальный релиз системы Журнала посещений v1.0.0-ja](https://github.com/eaststandart/techlab-journal-attendance/releases/tag/v1.0.0-ja)

---

## [v1.0.0-ja] — 2026-09-29
### Добавлено (Added)
* 🚀 Запущен новый раздел: **[Журнал посещений регулярных занятий](https://eaststandart.github.io/journal-attendance/)**.
* 📱 Реализована адаптивная верстка формы: преподаватели теперь могут удобно вести журнал с любого устройства (ПК, смартфоны, планшеты).
* 💬 Для родителей добавлена возможность в [дискусиях] (https://github.com/eaststandart/eaststandart.github.io/discussions/38?sort=new) отслеживать посещаемость онлайн и оставлять комментарии/вопросы прямо в ветке дискуссии.

### Изменено (Changed)
* ⚡ **Автоматизирован процесс отчетности:** время внесения данных и отправки формы сокращено до нескольких секунд.

### Инструкция по авторизации (Security)
* 🔐 Для ведения журнала преподавателю необходимо пройти авторизацию: зарегистрироваться на GitHub и сгенерировать `Personal access token` (`Fine-grained personal access token`). После этого открывается доступ к [форме отправки данных](https://eaststandart.github.io/journal-attendance/).
