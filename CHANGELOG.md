# Журнал изменений (Changelog)

Все заметные изменения в проекте «Лаборатории» будут фиксироваться в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com).

---

## — 2026-09-29
### Добавлено (Added)
* 🚀 Запущен новый раздел: **[Журнал посещений регулярных занятий](https://github.com)**.
* 📱 Реализована адаптивная верстка формы: преподаватели теперь могут удобно вести журнал с любого устройства (ПК, смартфоны, планшеты).
* 💬 Для родителей добавлена возможность отслеживать посещаемость онлайн и оставлять комментарии/вопросы прямо в ветке дискуссии.

### Изменено (Changed)
* ⚡ **Автоматизирован процесс отчетности:** время внесения данных и отправки формы сокращено до нескольких секунд.

### Инструкция по авторизации (Security)
* 🔐 Для ведения журнала преподавателю необходимо пройти авторизацию: зарегистрироваться на GitHub и сгенерировать `Personal access token` (`Fine-grained personal access token`). После этого открывается доступ к [форме отправки данных](https://github.io).

---
