# 🗺️ Дорожная карта проекта (Roadmap)

В этом документе описаны стратегические планы развития экосистемы «Лаборатории».

---

## 📅 Ближайшие планы (Осень — Зима 2027)

### 🤖 Автоматизация уведомлений
* [ ] **Интеграция с Telegram Bot API** — запуск бота для мгновенного информирования родителей о посещаемости (подробнее в [Issue #87](https://github.com/eaststandart/eaststandart.github.io/issues/87)). 
* [ ] **Кастомизация шаблонов сообщений** — разработка удобных текстовых шаблонов для push-уведомлений.

### 📝 Улучшение интерфейса и документации
* [ ] **Оптимизация формы для мобильных устройств** — повышение скорости загрузки интерфейса ведения журнала на смартфонах преподавателей.
* [ ] **Инструкции для команды** — создание пошагового руководства по быстрой генерации `Personal access token` на GitHub.

---

## 🔮 Перспективные идеи (2028)
* [ ] **Аналитический дашборд** — автоматический подсчет статистики посещаемости каждого ребенка за месяц/квартал.
* [ ] **Интеграция с календарями** — возможность автоматического экспорта расписания занятий в Google Календарь или Apple Calendar для родителей.
