# 🗺️ Дорожная карта проекта

В этом документе изложены глобальные цели, крупные вехи и векторы стратегического управления веб-платформой «Лаборатории». Данный план служит ориентиром для преподавателей, соавторов, руководства клуба и внешних команд, отражая долгосрочные направления развития, и обновляется по мере достижения ключевых этапов.

---

### 📅 Ближайшие планы

На текущий учебный год.

#### Автоматизация процессов контента
* [ ] Создать сценарий GitHub Actions для автоматического оборачивания добавленных в Discussions медиа-материалов регулярных занятий в соответствующие HTML-теги.
* [ ] Внедрить в конвейер автоматическое сжатие и преобразование загружаемых графических файлов в современный формат WebP для ускорения работы сайта.
* [ ] Сгенерировать стили отображения для видеоматериалов, аналогичные существующим правилам для тега figure.

#### Техническая оптимизация и контент
* [ ] Провести ревизию, структурировать и привести к единому стандарту CSS-стили основного сайта.
* [ ] Завершить информационное наполнение пустых разделов и страниц платформы.
