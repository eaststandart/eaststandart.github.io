# Тест короткого имени GitHub Video Attachment

Положи в эту папку ровно один исходный файл с расширением `.webm`.

Запуск из этой папки:

```bash
python -m pip install requests
python test_attachment_name.py
```

Перед запуском задай переменную окружения `MY_ADMIN_TOKEN` — используй тот же токен, который применяется текущим загрузчиком. Не записывай токен в файл и не отправляй его в чат.

Скрипт загрузит файл в GitHub Attachments репозитория `eaststandart/eaststandart.github.io`, передав имя `test-video.webm`. Исходный файл на диске не переименовывается. После загрузки скрипт выведет Markdown-ссылку для вставки в тестовую Discussion.

Важно: каждый запуск создаёт новое вложение GitHub. Не запускай скрипт повторно без необходимости.
