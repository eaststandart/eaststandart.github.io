### 🛠 Архитектура платформы и репозитории проекта

Веб-платформа **Творческой лаборатории познавательного развития** (Детско-юношеский инженерный клуб, г. Владивосток) построена на принципах открытого исходного кода (Open Source). Наш проект состоит из нескольких независимых модулей и систем автоматизации, развернутых на платформе GitHub.

Ниже представлен список ключевых репозиториев, из которых состоит экосистема клуба:

*   **[Основной сайт и экосистема](https://github.com)**
    Исходный код и текстовые материалы официального сайта клуба. Генерация статических страниц на движке Jekyll, интеграция интерактивных модулей и учебных проектов юных инженеров.
    
*   **[Система автоматизации журнала посещений](https://github.com)**
    Веб-интерфейс Журнала посещений регулярных занятий. Позволяет преподавателям клуба авторизоваться по персональным токенам и отправлять PUT-запросы с отметками присутствия учеников напрямую в базу данных репозитория в формате JSON.
    
*   **[Конструктор комментариев TechLab](https://github.com)**
    Вспомогательный инструмент автоматизации (Comment Builder) на языке Python, интегрированный в общую платформу для управления обсуждениями и обратной связью.

Чтобы организовать страницы внутри разделов как коллекции в Jekyll, вам нужно сделать два шага: прописать их в файле _config.yml и разложить файлы по специальным папкам с нижним подчеркиванием _.
В Jekyll коллекция — это папка, которая умеет автоматически собирать внутри себя однотипные страницы (например, список ваших инженеров или проектов) и генерировать для них правильные ссылки.
Вот как это устроено на техническом уровне:

Какое короткое имя для папки этой коллекции вам ближе: _architecture (Архитектура)

Шаг 1. Настройка в файле _config.yml

В вашем файле _config.yml уже частично прописаны коллекции. Чтобы движок Jekyll автоматически создавал для каждой страницы коллекции отдельную ссылку (URL) на сайте, у каждой коллекции обязательно должен стоять параметр output: true.
Откройте _config.yml и проверьте блок collections:. Для вашей новой структуры он должен выглядеть так:
yaml
collections:
  people:
    output: true
    permalink: "/people/:title/"
  engineers:
    output: true
    permalink: "/engineers/:title/"
  process:
    output: true
    permalink: "/process/:title/"
  architecture:               # Добавляем новую коллекцию для технической базы
    output: true
    permalink: "/architecture/:title/"
