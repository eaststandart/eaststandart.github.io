# Системные модули разметки

Каталог содержит переиспользуемые liquid-блоки кода, из которых движок Jekyll динамически собирает страницы сайта Лаборатории.

### Структура папки \_includes

```text
eaststandart.github.io/ 
└── _includes
    ├── discus.liquid           # Интеграция и вывод блока дискуссий giscus.
    ├── faire-grid.liquid       # Модуль автоматической сетки раздела «Ярмарка поделок».
    ├── footer.liquid           # Подвал сайта (копирайты, ссылки, контакты).
    ├── header-theme.liquid     # Смена логотипа главной страницы сайта.
    ├── media-archive.liquid    # Генерация и фильтрация общей ленты публикаций.
    ├── media-logic.liquid      # Глобальный модуль оптимизации медиаконтента.
    ├── navigation.liquid       # Модуль навигация по сайту.
    ├── news-loop.liquid        # Сборка и фильтрация ленты обновлений.
    ├── pagination.liquid       # Модуль пагинации страниц сайта.
    ├── posts-page.liquid       # Локальные ленты постов на страницах проектов.
    ├── tags-logic.liquid       # Сбор и генерация структуры тегов.
    ├── mathjax.html            # Подключение математического движка MathJax v3.
    └── README.md 
```

## Список файлов

*   **`discus.liquid`** — Для организации комментариев и Q&A под проектами.
*   **`faire-grid.liquid`** — Собирает все страницы внутри папки-раздела faire/ и выводит их в виде карточек. Оформление завязано на изолированные CSS-классы (.faire-list, .faire-card) в faire.css.
*   **`footer.liquid`** — Для организации внизу страниц копирайтов, ссылок, контактов.
*   **`header-theme.liquid`** — Быстрое изменение шапки главной страницы.
*   **`media-archive.liquid`** — ДОБАВИТЬ ОПИСАНИЕ.
*   **`media-logic.liquid`** — Подключение и последовательный запуск раздельных скриптов ленивой загрузки.
*   **`navigation.liquid`** — Вывод хлебных крошек, умных ссылок «Назад» и кнопки тегов на статьях.
*   **`news-loop.liquid`** — Сбор постов, страниц и людей, фильтрация по папкам, расчёт эмодзи и вывод.
*   **`pagination.liquid`** — ДОБАВИТЬ ОПИСАНИЕ.
*   **`posts-page.liquid`** — Вывод списков журнал, медиа внутри карточек конкретных проектов.
*   **`tags-logic.liquid`** — Полный сбор контента со всего сайта, сортировка и вывод групп.
*   **`mathjax.html `** — Подключение математического движка MathJax v3. Для корректного отображения формул из Obsidian через знаки \$ и \$$. Подключается только на страницах со свойством mathjax: true.
