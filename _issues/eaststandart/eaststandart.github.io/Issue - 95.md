# [Сайт] Добавить инструмент чтения и редактирования комментариев GitHub Discussions
## Задача
Реализовать отдельный инструмент для получения и редактирования Markdown-комментариев GitHub Discussions через GitHub GraphQL API.

## Требования
- Получать исходный Markdown комментария по Discussion и ID комментария.
- Передавать содержимое для анализа и подготовки изменений.
- Обновлять комментарий через updateDiscussionComment только после явного подтверждения.
- После обновления повторно получать комментарий и проверять сохранённый Markdown.
- Использовать существующую инфраструктуру GitHub Actions и обмен файлами через _input / _output, не затрагивая действующие механизмы публикации комментариев.
- Предусмотреть понятный статус выполнения и сообщения об ошибках.

## Предлагаемая реализация
Отдельный модуль discussion_editor.py и отдельный workflow/диспетчер по согласованной архитектуре. Для GraphQL использовать существующий GitHub token с необходимыми правами.

## Критерий готовности
Можно запросить Markdown конкретного комментария, подготовить его новую редакцию, подтвердить изменение и получить проверенный результат из GitHub.
