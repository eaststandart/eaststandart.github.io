# Шаблоны оформления страниц сайта

В папке \_layouts хранятся каркасы (скелеты) страниц. Jekyll берет текст из `.md` файлов страниц или постов сайта и подставляет его внутрь выбранного ниже шаблона.

### Структура папки \_layouts

```text
eaststandart.github.io/ 
├── _layouts 
│   └── default.md 
│   └── faire.md 
│   └── home.md 
│   └── news.md 
│   └── page.md 
```

### Список доступных шаблонов

*   **`default.md`** — Глобальный шаблон оформления страниц сайта.
*   **`home.md`** — Шаблон главной страницы сайта.
*   **`faire.md`** — Шаблон структуры страниц в разделе faire.
*   **`news.md`** — Шаблон ленты новостей и обновлений.
*   **`page.md`** — Шаблон для базовых страниц сайт.
