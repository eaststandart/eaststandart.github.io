# Шаблоны оформления страниц сайта (Layouts)

В этой папке хранятся каркасы (скелеты) страниц. Jekyll берет текст из ваших `.md` файлов и подставляет его внутрь выбранного здесь шаблона.

## Список доступных шаблонов

*   **`default.md`** — Глобальный шаблон оформления страниц сайта.
*   **`home.md`** — Шаблон главной страницы сайта.
*   **`faire.md`** — Шаблон структуры страниц в разделе faire.
*   **`news.md`** — Шаблон ленты новостей и обновлений.
*   **`page.md`** — Шаблон для базовых страниц сайт.
