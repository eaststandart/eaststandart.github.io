# Системные разделы и агрегаторы сайта

В данном каталоге находятся главные (индексные) страницы основных разделов Лаборатории, а также технические файлы-агрегаторы для автоматического сбора постов.

## Назначение страниц

*   **`faire.md`** — Раздел: Ярмарка поделок. Главная страница раздела для вывода списка всех дополнительных поделок.
*   **`people.md`** — Раздел: Люди. Страница со списком имен известных людей.

*   **`journal.md`** — Список постов из всех Журналов проектов. Выводит хронологическую ленту всех записей категории journal.
*   **`journal-posts-page.md`** — Список выборочных постов из Журналов проектов.
*   **`media.md`** — Список постов из всех Галерей проектов. Выводит хронологическую ленту всех записей папки media в формате Журнала.
*   **`media-posts-page.md`** — Записи выборочных постов из Галерей проектов.
*   **`news.md`** — Список всех новостей сайта. Содержит страницы и посты сайта.
