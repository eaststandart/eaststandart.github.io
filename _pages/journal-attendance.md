### 📋 Инструкция для преподавателей

Для получения доступа к журналу посещений вам понадобится личный персональный ключ (токен) GitHub. 

#### Шаг 1. Регистрация аккаунта
1. Зарегистрируйтесь на сайте [github.com](https://github.com) (если у вас ещё нет аккаунта).
2. Сообщите ваш **системный логин** (username) администратору, чтобы он создал для вас личное расписание.

#### Шаг 2. Создание секретного ключа доступа
1. Перейдите по прямой ссылке в настройки ключей: [GitHub Fine-grained Tokens](https://github.com).
2. Нажмите верхнюю кнопку **Generate new token**.
3. В поле **Token name** введите любое понятное название (например, `MyJournal`).
4. В строке **Expiration** (срок действия) выберите максимальный период (90 дней или выберите Custom на год).

#### Шаг 3. Настройка прав доступа к журналу
1. В блоке **Repository access** выберите пункт **Only select repositories**.
2. В появившемся списке найдите и выберите репозиторий: `eaststandart/eaststandart.github.io`.
3. Ниже раскройте вкладку **Permissions** ➔ **Repository permissions** и выставите два важных права:
   * **Contents:** выберите статус **Access: Read and write**
   * **Discussions:** выберите статус **Access: Read and write**
4. Прокрутите страницу в самый низ и нажмите зелёную кнопку **Generate token**.

#### Шаг 4. Вход в журнал
1. Обязательно **скопируйте** появившийся длинный ключ, начинающийся на `github_pat_...` (он показывается только один раз!).
2. Вернитесь на эту страницу журнала, вставьте ключ в поле ввода на самом верху и нажмите **🔓 Подключить журнал**. Браузер запомнит вас автоматически.
