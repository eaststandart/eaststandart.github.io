### Структура папки assets

```text
eaststandart.github.io/
└── assets/
    ├── batchfiles/  # Пакетные сценарии для вспомогательных операций.
    ├── css/         # Таблицы стилей сайта и его компонентов.
    ├── icons/       # Логотипы, иконки и другие графические ресурсы.
    └── js/          # JavaScript-код сайта.
```

### Назначение каталогов

- `batchfiles/` — пакетные сценарии для выполнения вспомогательных операций: генерации документации, построения дерева каталогов и оптимизации видео.
- `css/` — таблицы стилей, отвечающие за оформление сайта и его компонентов.
- `icons/` — логотипы, значки разделов сайта, изображения электронных компонентов, программ и другие графические материалы.
- `js/` — JavaScript-код сайта: отдельные скрипты и группы модулей для интерактивных функций и инструментов.
