# Пакетные файлы Windows (Batch Files)

В данном каталоге сосредоточена внутренняя инженерная логика автоматизации и обслуживания репозитория Лаборатории. Все утилиты написаны в виде пакетных сценариев Windows (командные файлы .bat), выполняются локально на компьютере администратора и предназначены для рутинной технической поддержки проекта.

### Структура папки batchfiles

```text
eaststandart.github.io/
└── assets/ 
    └── batchfiles/
        ├── generate_readme.bat     # Скрипт сбора описаний и документирования файлов
        ├── structure_tree.bat      # Скрипт для сбора дерева структуры репозитория
        ├── webm_optimization.bat   # Скрипт для оптимизации видео webm  
        └── README.md 
```

### Список скриптов

*   **`generate_readme.bat`** — Скрипт автоматического сбора описаний и документирования файлов папки.
*   **`structure.bat`** — Скрипт автоматической генерации интерактивной структуры дерева репозитория.
*   **`webm_optimization.bat `** — Скрипт пакетного поиска и веб-оптимизации демонстрационных видеороликов.
