# CSS стили оформления сайта Лаборатории

В данном каталоге сосредоточено графическое оформление и каскадные таблицы стилей (CSS) сайта Лаборатории. Файлы разбиты на изолированные модули, которые задают дизайн инженерной темы, управляют геометрией карточек и обеспечивают адаптивную верстку страниц под любые экраны.

### Структура папки css

```text
eaststandart.github.io/
└── assets/
    └── css/
        ├── biblio.css          # Сетка карточек для раздела Список литературы.
        ├── comment-builder.css # Модуль стилей веб-страницы формы комментариев.
        ├── diary.css           # Сетка карточек для раздела Дневник инженера.
        ├── faire.css           # Сетка карточек для раздела Ярмарки поделок.
        ├── footnotes.css       # Верстка примечаний и текстовых сносок со стрелками возврата.
        ├── giscus-gallery.css  # Модуль изолированных стилей страницы дискуссий Галерея раздела Ярмарка поделок.
        ├── giscus-process.css  # Модуль изолированных стилей страницы дискуссий раздела Творческий процесс.
        ├── giscus-v1.0.css     # Первая версия пользовательского оформления комментариев Giscus.
        ├── giscus-v1.1-0.css   # Версия пользовательского оформления Giscus для раздела творческого процесса.
        ├── giscus.css          # Адаптивная фиксация ширины виджета комментариев Giscus.
        ├── header-classic.css  # Центрированная шапка сайта с логотипом.
        ├── header-desktop.css  # Тестовый модуль шапки с имитацией консоли ввода команд.
        ├── header-panel.css    # Релизная верхняя панель бренда с кнопками и консолью.
        ├── images.css          # Модуль изображений.
        ├── journal-attendance.css # Модуль стилей веб-страницы журнала посещений.
        ├── pagination.css      # Модуль кнопок пагинации, навигации и лент новостей.
        ├── projects.css        # Сетка карточек для раздела Учебные проекты.
        ├── style.css           # Глобальное ядро темы, цвета, переменные и геометрия страниц.
        ├── tools.css           # Сетка карточек для раздела Полезные инструменты.
        ├── video-figure-v.css  # Модуль оформления вертикальных видеоблоков.
        ├── video-figure.css    # Модуль оформления одиночных видеоблоков с подписями.
        ├── video-gallery.css   # Модуль оформления галерейных рядов видеороликов.
        ├── video.css           # Ряд видеоплееров .webm, заглушки и защита от прыжков.
        └── zoom.css            # Модуль центрированного модального зума (Лайтбокса) для картинок.
```

### Список стилей

*   **`biblio.css`** — Формирует компактную вертикальную ленту адаптивных карточек книг с автоматической подгонкой обложек, ограничением длинных заголовков и сокращением описаний.
*   **`comment-builder.css`** — Оформляет интерфейс авторизации и форму отправки комментариев в обсуждения.
*   **`diary.css`** — Создает вертикальную ленту рабочих заметок с единым шагом, миниатюрами и адаптацией текста для мобильных экранов.
*   **`faire.css`** — Формирует адаптивную сетку карточек моделей для раздела Ярмарки поделок.
*   **`footnotes.css`** — Оформляет списки примечаний и сносок, включая интерактивную стрелку возврата к тексту.
*   **`giscus-gallery.css`** — Назначение в шапке файла не указано.
*   **`giscus-process.css`** — Назначение в шапке файла не указано.
*   **`giscus-v1.0.css`** — Подключает светлую тему Giscus и корректирует отображение изображений и отступов в комментариях.
*   **`giscus-v1.1-0.css`** — Подключает светлую тему Giscus и настраивает отступы текстовых блоков и элементов комментариев.
*   **`giscus.css`** — Фиксирует ширину фрейма комментариев в границах контентной области на смартфонах и планшетах.
*   **`header-classic.css`** — Формирует центрированную шапку сайта с аватаром и адаптацией размеров под мобильные экраны.
*   **`header-desktop.css`** — Формирует тестовую двухъярусную шапку с псевдоконсолью и адаптацией для мобильных экранов.
*   **`header-panel.css`** — Задает геометрию и адаптивность верхней панели бренда с кнопками и полем ввода консоли.
*   **`images.css`** — Задает размеры изображений, предотвращает сдвиги страницы при загрузке и управляет адаптивностью одиночных изображений и галерей.
*   **`journal-attendance.css`** — Оформляет интерфейс авторизации, календарную сетку и списки групп журнала посещений.
*   **`pagination.css`** — Объединяет стили списков новостей, архивов, локальных лент, хлебных крошек и интерфейсов пагинации.
*   **`projects.css`** — Формирует адаптивную сетку категорий учебных проектов с миниатюрами и мобильной перестройкой.
*   **`style.css`** — Интегрирует глобальные цветовые переменные, геометрию, шрифты, контейнеры, галереи, теги и адаптивные правила сайта.
*   **`tools.css`** — Формирует вертикальную ленту обзоров программного обеспечения с логотипами и адаптацией описаний.
*   **`video-figure-v.css`** — Настраивает контейнеры и адаптивное отображение вертикальных видео в одиночных figure-блоках.
*   **`video-figure.css`** — Формирует адаптивные figure-видеоблоки, их центрирование и размеры видеоплееров.
*   **`video-gallery.css`** — Формирует адаптивные flex-ряды видеоплееров без подписей и управляет их расположением.
*   **`video.css`** — Формирует адаптивные ряды видеоплееров, заглушки и защиту от сдвигов макета при загрузке.
*   **`zoom.css`** — Реализует модальный зум изображений с затемнением и размытием фона и фиксированными безопасными отступами.
