# CSS стили оформления сайта

В данном каталоге сосредоточена внутренняя инженерная логика автоматизации и обслуживания репозитория Лаборатории. Все утилиты написаны в виде пакетных сценариев Windows (командные файлы .bat), выполняются локально на компьютере администратора и предназначены для рутинной технической поддержки проекта.

### Структура папки css

```text
eaststandart.github.io/
└── assets/

        ├── diary.css

        ├── img.css 
        ├── pagination.css 
        ├── projects.css 
        ├── style.css 
        ├── tools.css 
        ├── video.css 
        └── README.md 
```
