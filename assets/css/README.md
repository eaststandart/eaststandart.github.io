# CSS стили оформления сайта Лаборатории

В данном каталоге сосредоточено графическое оформление и каскадные таблицы стилей (CSS) сайта Лаборатории. Файлы разбиты на изолированные модули, которые задают дизайн инженерной темы, управляют геометрией карточек и обеспечивают адаптивную верстку страниц под любые экраны.

### Структура папки css

```text
eaststandart.github.io/
└── assets/ 
    └── css/ 
        ├── biblio.css 
        ├── diary.css 
        ├── faire.css 
        ├── footnotes.css 
        ├── giscus.css 
        ├── header-classic.css 
        ├── header-desktop.css 
        ├── header-panel.css 
        ├── img.css 
        ├── pagination.css 
        ├── projects.css 
        ├── style.css 
        ├── tools.css 
        ├── video.css 
        └── README.md 
```

### Список стилей

*   **`biblio.css`** — Сетка карточек для раздела Список литературы.
*   **`diary.css`** — Сетка карточек для раздела Дневник инженера.
*   **`faire.css`** — Сетка карточек для раздела Ярмарки поделок.
*   **`footnotes.css`** — Верстка примечаний и текстовых сносок со стрелками возврата.
*   **`giscus.css`** — Адаптивная фиксация ширины виджета комментариев Giscus.
*   **`header-classic.css`** — Центрированная шапка сайта с логотипом.
*   **`header-desktop.css`** — Тестовый модуль шапки с имитацией консоли ввода команд.
*   **`header-panel.css`** — Релизная верхняя панель бренда с кнопками и консолью.
*   **`img.css`** — Защита от прыжков при загрузке изображений.
*   **`pagination.css`** — Модуль кнопок пагинации, навигации и лент новостей.
*   **`projects.css`** — Сетка карточек для раздела Учебные проекты.
*   **`style.css`** — Глобальное ядро темы, цвета, переменные и геометрия страниц.
*   **`tools.css`** — Сетка карточек для раздела Полезные инструменты.
*   **`video.css`** — Ряд видеоплееров .webm, заглушки и защита от прыжков.
