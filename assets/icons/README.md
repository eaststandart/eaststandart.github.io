# Графические ресурсы сайта

В каталоге собраны графические материалы, используемые на страницах сайта: логотипы, значки разделов, изображения электронных компонентов, программ и учебных материалов.

### Структура папки icons

```text
eaststandart.github.io/
└── assets/
    └── icons/
        ├── aluminum-electrolytic-capacitor.webp  # Изображение алюминиевого электролитического конденсатора.
        ├── analog-panel-meter.webp               # Изображение аналогового щитового измерительного прибора.
        ├── carbon-film-resistor.webp             # Изображение углеродистого плёночного резистора.
        ├── ceramic-disc-capacitor.webp           # Изображение керамического дискового конденсатора.
        ├── chto-novogo.svg                       # Графический значок раздела «Что нового».
        ├── detskij-inzhenernyj-klub.svg          # Логотип детского инженерного клуба.
        ├── favicon.svg                           # Значок сайта для браузера.
        ├── fritzing.webp                         # Изображение программы Fritzing.
        ├── getting-started-in-electronics.webp   # Изображение учебного материала по основам электроники.
        ├── logo-github.svg                       # Логотип GitHub.
        ├── logo-readme.svg                       # Графический логотип для README.
        ├── logo-telegram.svg                     # Логотип Telegram.
        ├── logo.svg                              # Основной логотип сайта.
        ├── magnetic-buzzer.webp                  # Изображение магнитного зуммера.
        ├── our-dream.webp                        # Иллюстрация «Our Dream».
        ├── sprintlayout.webp                     # Изображение программы Sprint-Layout.
        ├── strontium-atom.webp                   # Изображение атома стронция.
        ├── through-hole-red-led.webp             # Изображение красного светодиода с выводами.
        └── ugolok-mladshego-konstruktora.svg     # Значок раздела «Уголок младшего конструктора».
```

### Назначение файлов

- **Изображения электронных компонентов** — иллюстрации конденсаторов, резистора, измерительного прибора, зуммера и светодиода.
- **Графика разделов сайта** — значки «Что нового», «Детский инженерный клуб» и «Уголок младшего конструктора».
- **Логотипы и значки сервисов** — графика сайта, README, GitHub, Telegram и favicon.
- **Иллюстрации программ и учебных материалов** — изображения Fritzing, Sprint-Layout, основ электроники и другие тематические материалы.
