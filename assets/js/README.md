# Интерактивные скрипты проекта (JavaScript)

В данном каталоге сосредоточена клиентская логика Творческой лаборатории. Все модули написаны на чистом JS без тяжелых внешних зависимостей для обеспечения максимальной скорости загрузки страниц.

## Описание компонентов ядра

*   **`image-lazy-load.js`** — Модуль лези-лоада картинок. Экономит трафик пользователей, откладывая загрузку изображений поделок до момента их появления на экране.
*   **`video-lazy-load.js`** — Модуль лези-лоада видеоплееров. Позволяет мгновенно открывать страницы проектов с демонстрационными `.webm` файлами без просадки производительности.
*   **`navigation-crumbs.js`** — Движок хлебных крошек навигации. Автоматически строит цепочку пути для удобного возврата в родительские разделы.
*   **`pagination-logic.js`** — Движок пагинации. Отвечает за разбиение длинных списков публикаций на страницы.
*   **`posts-page-nav.js`** — Движок локальной пагинации проектов. Обеспечивает навигацию между связанными записями.
*   **`posts-page-list.js`** — Движок фильтрации и зачистки ленты медиа. Управляет отображением контента в зависимости от выбранного режима.
*   **`tags-search.js`** — Движок js-фильтрации страницы поиска по тегам. Позволяет мгновенно находить нужные схемы и роботов прямо в браузере.
