# Интерактивные скрипты проекта

В данном каталоге сосредоточена клиентская логика сайта Лаборатории. Все модули написаны на чистом JavaScript (JS) без тяжелых внешних зависимостей для обеспечения максимальной скорости загрузки страниц.

### Структура папки js

```text
eaststandart.github.io/
├── assets/
│   └── js/
│       ├── comment-builder/       # Модули Конструктора комментариев: форма, черновики, медиа и публикация.
│       ├── journal-attendance/    # Модули Журнала посещений: авторизация, данные, интерфейс, команды и проверка.
│       ├── image-lazy-load.js     # Отложенная загрузка изображений.
│       ├── pagination-logic.js    # Логика пагинации.
│       ├── posts-page-list.js     # Формирование и фильтрация списка публикаций.
│       ├── posts-page-nav.js      # Навигация по страницам проектов.
│       ├── tags-search.js         # Поиск и фильтрация материалов по тегам.
│       ├── video-lazy-load.js     # Отложенная загрузка видеоплееров.
│       ├── zoom.js                # Увеличение изображений.
│       └── README.md              # Описание структуры и назначения скриптов.
```

### Назначение папок

* **`comment-builder/`** — отдельные JavaScript-модули Конструктора комментариев: авторизация, форма, черновики, проверка данных, медиа и отправка.
* **`journal-attendance/`** — отдельные JavaScript-модули Журнала посещений: авторизация, загрузка и обработка данных, интерфейс, команды и проверка.

### Список скриптов

*   **`image-lazy-load.js`** — Модуль отложенной загрузки изображений.
*   **`pagination-logic.js`** — Модуль пагинации.
*   **`posts-page-list.js`** — Модуль фильтрации и зачистки ленты медиа.
*   **`posts-page-nav.js`** — Модуль локальной пагинации проектов.
*   **`tags-search.js`** — Модуль js-фильтрации страницы поиска по тегам.
*   **`video-lazy-load.js`** — Модуль лези-лоада видеоплееров.
*   **`zoom.js`** — Модуль увеличения изображений.
