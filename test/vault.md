## Группа 1: Исключения строчного кода (Inline Code)

1-1. Запись: Ссылка журнального блока внутри одиночных бэктиков
   
Пример строчного кода журнального кадра: `![{fig}|Скрытый текст подписи](/test/folder/test.webp)`

1-2. Запись: Ссылка базовой картинки внутри одиночных бэктиков
   
Пример строчного кода базовой картинки: `![{v}|Вертикальный базовый кадр](/test/folder/test.webp)`


## Группа 2: Исключения многострочных блоков кода (Fenced Code Blocks)

2-1. Запись: Пример журнального блока и базовой картинки внутри маркдаун-кода
   
```markdown
![{fig}](/test/folder/test.webp)
![](test/folder/test.webp)
![{fig|v}|Живой текст](/test/folder/test.webp)
```
